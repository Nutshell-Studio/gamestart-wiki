    Modding

    GameStart's store stock is data-driven, and the game has built-in, player-visible modding surfaces: packs, content pack files (.gspack), and the title bank.

    Pre-release note: the pack formats are still evolving. Packs you make today may need updates as the game develops.

    Packs

    A pack is a folder of content that changes what fills the store: exclude games from the shelves, rename the fictional titles, or restrict which platform sections a game may stock.

    On the title menu's MODS screen you can:

    • See every installed pack (it says "No packs installed" until you add one).
    • Enable/disable each pack with its toggle.
    • See each pack's load order (#1, #2, …) — later packs win when two packs touch the same game.
    • Click "Open packs folder" to jump straight to where packs live on disk.

    Packs now shape the night shift too: excluded games leave the pool the store stocks from, platform limits keep a game to its chosen sections, and fictional renames appear on box names. These changes decide which world a New Game builds — an existing save keeps the world it was made with, and its Continue will tell you if the pack set changed under it. Hiding games this way applies to the real titles; hiding a fictional title takes effect in the classic browse mode only.

    Installing a pack

    1. On the title menu, open MODS and click "Open packs folder".
    2. Drop the pack's folder in there (one folder per pack).
    3. Back in the game, enable it with its toggle — it applies the next time you visit the store.

    Content packs (.gspack)

    A content pack is a single .gspack file that can carry deeper, gameplay- shaping data — today that means skills and talents (the gear you unlock and the talent trees behind it), with more content kinds on the same road. Packs are data only: no code ever runs from a pack, and every pack is strictly validated on load — a broken pack is skipped with a message, never a crash.

    To install one: drop the .gspack file into the Mods folder next to your saves (%USERPROFILE%\AppData\LocalLow\<studio>\<game>\Mods). Rename it to <name>.gspack.disabled to switch it off. Load order is alphabetical; a pack made with gameplay content stamps itself into your save, so a save made with mods will refuse to continue if the mod set changes (protecting the save, not punishing you — restore the packs and it loads again).

    The title bank

    The fictional titles on the boxes come from word banks you can replace: create Mods\titlebank.json with your own words —

    {
  "sp3aNames": ["My Favorite Fake Game"],
  "adjectives": ["Copperleaf", "Mossy"],
  "nouns": ["Harbor", "Junction"]
}

    — and the store names its stock from your banks on the next launch. Real trademarks are refused (the whole file is skipped if any word matches the deny list), and a malformed file just falls back to the built-in names.

    Custom sounds

    The store's sounds are swappable, one file per sound: drop 16-bit WAV files into Mods\audio\ named for the sound they replace —

    pick.wav · place.wav · refuse.wav · complete.wav · chime.wav · footstep_a.wav · footstep_b.wav · ambient_loop.wav · kiosk_loop.wav

    A file that isn't a plain 16-bit WAV is skipped with a note and the built-in sound keeps playing. Sounds are cosmetic — they never affect saves or playing together.

    Translations

    Content pack files can carry translations: a pack's language files replace any translated line of the game's text, and untranslated lines keep their English. Translations are cosmetic like sounds — installing one never affects a save. The game itself now ships Japanese, Simplified Chinese, and Traditional Chinese (Taiwan and Hong Kong), Korean, Portuguese - Brazil, French, German — pick a language in Settings under GRAPHICS — and every line of the game's text is translatable, so a pack can polish a shipped language or start a brand-new one. The Hong Kong option is Standard Written Chinese with Hong Kong wording (網絡, 私隱, 地下 for the ground floor, 閣樓 for the mezzanine) on top of the Taiwan text — not colloquial Cantonese. Plural lines may carry .one, .few and .many variants; a pack that only fills .many still works.

    Steam Workshop

    The first slice of Workshop support is in the game: subscribe to a GameStart Workshop item and the game installs it on the next launch — .gspack files land in Mods, folder packs land on the MODS screen. Unsubscribe and it's removed the same way. (Publishing tools and the public Workshop hub go live with the Steam release — until then packs travel by file sharing, exactly as above.)

    Planned next: sharable presets of your store settings, so you can hand a friend your whole store setup in one go.

    Making a pack

    The honest answer for now: the formats are documented for developers rather than polished for creators — a folder pack is a set of plain-text files, and a content pack is built with the in-editor Pack Workbench. If you're comfortable poking at files, see the Dev Glossary for where the technical documentation lives.

    What packs can't touch

    Packs can curate which games appear in the store, but they cannot switch the Steam connection on for you. That choice always remains yours — see Privacy. Packs also can't run code, load DLLs, or reach outside their own data — by design.
