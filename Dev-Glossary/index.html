    Dev Glossary

    This page is developer/modder-facing. It is the only wiki page allowed to use internal names — everywhere else the wiki speaks strictly in player terms (that rule is machine-checked by tools/wiki-term-lint/). If you're a player, you want the Glossary.

    Player term → internal term

    Player term (wiki) Internal term (code/docs) Notes
    a game / a title (all its copies) SKU (ProductSKU) "SKU complete" = all copies homed — the atomic progress beat
    shelf row / run of games slot strip (SlotStrip, GsShelfSlot) slots grouped on a strip; strips carry the price-tag rail
    what you're carrying / held stack held ring (HeldRing) the 2 / 5 HUD counter is its index
    price tag (white/red) PriceTagRail / PriceTagLedger / PriceTagController one tag per title-run, derived on every strip change
    Free Basket floor-freeslots / GsStoreSectionIds.FloorFreeSlots manual, non-penalized destination; excluded from persistent SKU-home ownership
    section zone (ZoneDef, ShelfZone) NewWall / UsedWall / Counter / Floor
    section sign lighting up GsSectionBeats predicate + mat_gs_header_* state variants persistence lands with v4
    pack curation manifest pack (GsCurationIO, packs at <game data>/Curation/Packs/) the in-game packs screen is GsFictionalScreen
    fictional catalog curation-built deterministic catalog same-library ⇒ same store (catalog-hash-guarded)
    terminal GsTerminalPage + CRT render path counter-only; the portable parody retired with the legacy gear sweep
    ghost preview / matching-glow GsInteractor placement preview / same-def outline outline gates behind the Stock Sense passive in v4
    tidying progress GsProgress stateless strip recount shift wrapper removed in v4
    the store / title screens GsStore.unity / GsTitle.unity the two shipping scenes
    Steam connection Steam Web API fetch, opt-in, runtime-only covers cache: CoverCache/; never bundled, never uploaded
    quiz fixtures quiz zones (v4 spec §4) deterministic slot layout from library stats
    setting an answer while keeping the held copy ReferenceAnswer quiz mode resolver-owned virtual answer; no physical slot occupancy or inventory transfer
    talent points talent economy (v4 spec §5) replaces wallet/cents
    store gadgets parody gear ladder (v4 spec §5) names pending Brand Bible naming pass
    the six signature skills — Hold Piece, Pip-Boy, Bubble Carry, Plumbob Guide, Portal Return, Tendril Grab retired safe names Shelf Swap / Stocktake Scanner / Bubble Post / Guide Gem / Return Gate / Reel Grab (rights register RR-020..025) names reverted to the originals per owner ruling 2026-07-20; the safe names are the prepared fallbacks and stay out of player pages (lint-checked); wire ids (swap_shelf, scan_info, bubble_float, plumbob_guide, portal_place, tendril_pull) and gear.* ids keep their old spellings
    Portal Pistol portal_pistol / gear.portal_pistol (GsPortalPistolCore/Host/Effect, Tool 6) added by owner ruling 2026-07-21 (Tool-6 wave, reverses ruling E's five-slot cap); brand-new skill, not a rename — rights-register row pending
